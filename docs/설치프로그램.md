# 출석 관리 설치 프로그램

학원 PC에 **서버 + 데스크톱 프로그램 + Android 앱**을 한 번에 설치하는 프로그램입니다.
Java가 따로 필요 없고(런타임 포함), 관리자 권한은 방화벽 설정에서만 한 번 요청합니다.

## 만들기 (개발자)

```
powershell -ExecutionPolicy Bypass -File build_setup.ps1 -RebuildApp
```

- `-RebuildApp` : 앱/서버를 먼저 새로 빌드합니다 (`build_dist.ps1`). 이미 빌드해 두었다면 생략할 수 있습니다.
- `-ApkPath <경로>` : Android APK를 직접 지정합니다. 생략하면 Android 프로젝트의 `app\build\outputs\apk\debug`에서
  **가장 최근 APK**(파일 이름은 상관없음)를 씁니다. 먼저 Android 프로젝트에서 `gradlew assembleDebug`로 빌드해 두세요.
- `-NoSfx` : 단일 파일(`AttendanceSetup.exe`) 만들기를 건너뛰고 폴더판만 만듭니다 (더 빠름).
- 결과
  - `dist\AttendanceSetup.exe` : **단일 파일**(Windows 내장 IExpress). 이것만 학원에 전달하면 됩니다.
  - `dist\AttendanceSetup\` : 같은 내용의 폴더판 (`AttendanceSetup.exe` + `payload\` + `runtime\`). 단일 파일이 안 열리는 PC에서 사용.
- 구글 드라이브 동기화를 쓰려면 `google-client.json`을 `C:\Java_Assignment\`에 두고 빌드하세요 (`docs\구글드라이브_동기화_설정.md`).

## 설치 (학원)

1. `AttendanceSetup.exe`를 실행합니다. (SmartScreen이 "알 수 없는 게시자"라고 경고하면 **추가 정보 → 실행**)
2. 마법사의 안내를 따릅니다: 설치 위치와 옵션을 고르고 **설치**.
   - 바탕화면 바로가기 / 시작 메뉴 등록
   - **Windows를 켤 때 자동 실행(백그라운드)** — 켜 두면 창 없이 서버만 실행되어 폰이 언제든 연결됩니다
   - **방화벽 자동 설정(권장)** — 관리자 권한 요청이 한 번 나옵니다. [예]를 눌러주세요
   - **Android 앱 설치** — USB로 연결된 폰이 있으면 자동 설치, 없으면 **QR 코드**를 보여줍니다
3. 설치가 끝나면 Android 설치 안내(QR)가 나옵니다. 폰이 이 PC와 **같은 Wi-Fi**에 있어야 합니다.
   폰 카메라로 QR을 스캔 → 내려받은 파일 열기 → 설치 (필요하면 "출처를 알 수 없는 앱 설치" 허용).
   QR 주소는 **설치 창이 열려 있는 동안만** 제공됩니다.
4. **마침**을 누르면 프로그램이 실행됩니다.

기본 설치 위치는 `%LOCALAPPDATA%\Programs\AttendanceManager`(관리자 권한 불필요)입니다.

## 설치 프로그램이 자동으로 설정하는 것

| 항목 | 내용 |
|---|---|
| 프로그램 파일 | 데스크톱 앱, 내장 서버, Java 런타임, `AttendanceApp.apk`(다른 폰에 설치할 때 사용) |
| 서버 포트 | 기본 18080. Hyper-V/WSL이 예약했거나 다른 프로그램이 쓰고 있으면 자동으로 다른 포트(28080 등)를 골라 `~\.attendance-desktop\settings.properties`에 기록 |
| 방화벽 | TCP(서버 포트)와 UDP 18081(폰 자동 검색) 허용 규칙 |
| 바로가기 | 바탕화면(OneDrive로 옮겨진 바탕화면 포함), 시작 메뉴(실행 + 제거) |
| 제거 정보 | Windows 설정 > 앱 목록에 "출석 관리 프로그램" 등록 |
| 자동 실행 | (선택) `HKCU\...\Run`에 `--background`로 등록 |
| Android | adb로 USB 설치 또는 QR 코드/주소 제공 |

## 업데이트

같은 설치 프로그램을 다시 실행하면 됩니다. 실행 중인 프로그램은 **저장·백업·드라이브 동기화까지 마치고** 자동으로 종료되고,
프로그램 파일만 새 버전으로 바뀝니다. **출석 데이터(`~\.attendance-desktop`)는 건드리지 않습니다.**

## 제거

Windows 설정 → 앱 → **출석 관리 프로그램** → 제거 (또는 시작 메뉴의 "출석 관리 제거").
바로가기, 앱 목록 등록, 자동 실행, 방화벽 규칙, 프로그램 파일을 지웁니다(방화벽 때문에 관리자 권한 요청이 한 번 나옵니다).
**출석 데이터는 기본적으로 남겨 둡니다.** 제거 창의 체크박스를 선택하면 데이터(DB, 백업, 구글 로그인 정보)도 삭제합니다.

## 명령줄 옵션 (일괄 설치, 시험용)

```
AttendanceSetup.exe --silent --install-dir "D:\출석 관리" --autostart --no-launch
```

`--silent`(화면 없이) `--install-dir <경로>` `--no-desktop-shortcut` `--no-start-menu` `--autostart` `--no-firewall` `--no-android`
`--no-launch` `--port <번호>` / 제거: `--uninstall [--silent] [--delete-data] [--no-firewall]`

(단일 파일판은 옵션을 받지 않습니다. 옵션이 필요하면 폴더판 `dist\AttendanceSetup\AttendanceSetup.exe`를 쓰세요.)

## 한계와 알아둘 점

- **서명되지 않은 프로그램**이라 Windows SmartScreen 경고가 뜹니다. 없애려면 코드 서명 인증서가 필요합니다.
- Android 앱은 **디버그 서명** APK입니다. 폰에 이미 다른 서명의 같은 앱이 있으면 먼저 지워야 설치됩니다.
- USB 자동 설치는 **adb**(Android SDK platform-tools)가 PC에 있고 폰의 USB 디버깅이 켜져 있을 때만 됩니다. 아니면 QR 방식이 사용됩니다.
- UDP 18081(폰 자동 검색)을 쓸 수 없는 PC에서는 폰 앱의 **[서버 주소 직접 입력]**으로 연결해야 합니다 (설치 중 경고로 알려줍니다).
