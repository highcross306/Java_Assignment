# 구글 드라이브 동기화 설정 (개발자용, 최초 1회)

출석 데이터를 **암호화**해서 구글 드라이브의 **앱 전용 숨김 폴더**에 올리고, 다른 PC에서도 같은
데이터를 쓰게 해주는 기능입니다. 이 기능을 쓰려면 개발자가 구글 클라우드 콘솔에서 **OAuth 클라이언트 ID**를
한 번 만들어 `google-client.json`으로 배포해야 합니다. (학원은 구글 로그인만 하면 됩니다.)

## 1. 구글 클라우드 콘솔에서 준비

1. <https://console.cloud.google.com> 에서 새 프로젝트를 만듭니다.
2. **API 및 서비스 → 라이브러리**에서 **Google Drive API**를 "사용"으로 켭니다.
3. **API 및 서비스 → OAuth 동의 화면**을 설정합니다.
   - 앱 이름, 지원 이메일, 개발자 연락처를 입력합니다.
   - **범위(Scopes)** 에는 아래 3개만 추가합니다. (다른 드라이브 파일에는 접근하지 않습니다)
     - `openid`, `email` (로그인한 계정 표시용)
     - `https://www.googleapis.com/auth/drive.appdata` (이 앱 전용 숨김 폴더)
4. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **데스크톱 앱**
   - 만들면 나오는 JSON을 내려받습니다.

## 2. 앱에 넣기

### 방법 A: 프로그램에서 직접 입력 (가장 쉬움)
- 프로그램의 **설정 → 구글 드라이브 동기화**에서 동의 항목을 체크하고 **[자동 동기화 허용]** 을 누르면,
  설정 파일이 없을 때 **입력창**이 나옵니다.
- **클라이언트 ID**와 **클라이언트 보안 비밀(Client secret)** 을 입력하거나, 콘솔에서 내려받은 JSON 파일을
  **[JSON 파일 불러오기]** 로 불러오면 두 칸이 자동으로 채워집니다. **[구글 콘솔 열기]** 로 발급 화면을 열 수 있습니다.
- 확인을 누르면 프로그램이 **`google-client.json`을 자동으로 만들어** `C:\Users\<사용자>\.attendance-desktop\`에 저장하고
  바로 구글 로그인으로 이어집니다. (이 두 값은 구글 콘솔에서 발급받는 값이라 프로그램이 대신 만들 수는 없습니다.)
- 입력하는 PC마다 한 번씩 필요합니다. 여러 PC에 같은 값을 쓰려면 아래 방법 B로 배포본에 넣어두면 입력이 필요 없습니다.

### 방법 B: 배포본에 미리 넣기 (학원에는 입력을 시키지 않고 싶을 때)
- 내려받은 JSON 파일 이름을 **`google-client.json`** 으로 바꿔서 `C:\Java_Assignment\` (build_dist.ps1이 있는 폴더)에 둡니다.
  이 파일은 `.gitignore`에 들어 있어 저장소에 올라가지 않습니다.
- `build_dist.ps1`을 실행하면 배포 폴더의 `app\google-client.json`으로 함께 복사됩니다.
- 이미 배포한 PC에는 `app\` 폴더 또는 `C:\Users\<사용자>\.attendance-desktop\` 폴더에 직접 넣어도 됩니다.

## 3. 배포 전에 꼭 확인할 것 (구글 정책 — 최신 문서로 재확인 필요)

- OAuth 동의 화면이 **"테스트" 상태**이면 등록한 테스트 사용자만 로그인할 수 있고, 로그인 유지(refresh token)가
  **7일 후 만료**되는 것으로 알고 있습니다. 실제 학원에 배포하려면 **"프로덕션으로 게시"** 해야 합니다.
- `drive.appdata` 범위는 민감하지 않은 범위로 분류되는 것으로 알고 있어 간단한 게시 절차로 가능할 것으로
  보이지만, 구글이 요구하는 심사(개인정보처리방침 URL, 앱 도메인 확인 등)가 있는지는 게시할 때 콘솔 안내를 따르세요.

## 4. 사용 방법 (학원)

1. 프로그램 왼쪽의 **구글 드라이브 동기화** → **구글 계정으로 동기화 켜기**
2. 브라우저에서 구글 로그인 (드라이브 항목을 체크해야 합니다)
3. **처음 켜는 PC**: 동기화 비밀번호를 정합니다. **잊어버리면 드라이브의 데이터를 복구할 수 없습니다.**
4. **다른 PC**: 같은 구글 계정으로 로그인하고 같은 동기화 비밀번호를 입력합니다. 드라이브 데이터를 쓸지,
   이 PC 데이터로 덮어쓸지 선택합니다.

## 5. 동작 원칙

- 프로그램을 **켤 때** 드라이브에 더 새로운 버전이 있으면 받아오고, **끌 때** 데이터가 바뀌었으면 올립니다.
- 두 PC가 **동시에** 같은 데이터를 바꾸면, 나중에 끄는 PC는 드라이브를 덮어쓰지 않고 건너뜁니다.
  다음 실행 때 "드라이브 데이터 사용 / 이 PC 데이터 유지 / 나중에" 중에서 고릅니다.
- 이 PC의 데이터를 교체하기 전에는 항상 `backups` 폴더에 `before-sync-*` 파일로 보관합니다.
- 암호화: AES-256-GCM, 키는 동기화 비밀번호에서 PBKDF2(600,000회)로 만듭니다. 구글에는 암호문만 올라갑니다.
- 동기화 키는 편의상(종료 시 자동 업로드) 이 PC의 `.attendance-desktop\sync-state.json`에도 저장됩니다.
  이 폴더는 DB 파일과 같은 수준으로 보호해야 합니다.
- 한 번에 한 PC에서만 프로그램을 쓰는 것을 권장합니다. (실시간 동기화가 아니라 켤 때/끌 때 동기화입니다.)
